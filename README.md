## ✦ Atelier Provenance & Design Manifesto

> *“At KHAIRA, I reject the ephemeral churn of fast fashion. Instead, I anchor each silhouette in sculptural permanence, marrying the structural precision of bespoke tailoring with the fluid, unstitched grace of historical Indian drapery.”*
> — **Praweena NS**, Founder of KHAIRA Atelier &amp; Co-Founder of Floral Fusion

Rooted in the renowned textile capital of **Tiruppur and Coimbatore, Tamil Nadu**, KHAIRA Atelier operates at the intersection of ancestral Indian handloom heritage and modern silhouette architecture. 

* **Runway Showcases**: Three debut thematic collections staged across regional fashion platforms, exploring silhouette scaling across generations, 3D organza surface manipulation, and celestial avant-garde menswear and womenswear.
* **Artisanal Ventures**: Co-founder of **Floral Fusion**, an artisanal luxury gifting venture celebrating tactile botantical aesthetics.
* **Scholarship**: Academic costume design research investigating Ahimsa (cruelty-free) sericulture, zero-waste pattern cutting algorithms, and Kovai Kora cotton-silk handloom physics.

## ✦ Signature Architectural Features

### 1. Viewport-Aware Editorial Hero (`src/components/home/Hero.tsx`)
* Engineered for 100% above-the-fold fit across standard desktop viewports (1280×720, 1440×900, and 1920×1080).
* Houses the founder portrait frame with zero bottom fold slicing, the floating atelier credential badge, and the three-column metrics strip (`KHAIRA • Label Founded`, `Ahimsa • Cruelty-Free Silk`, `Bespoke • Custom Silhouettes`).

### 2. Time-Aware Day &amp; Night Atelier Engine
* **0ms Pre-Paint Blocking Script**: Evaluates in `<head>` before HTML rendering to eliminate flash-of-unstyled-theme (FOUC).
* **Astronomical Clock Heuristic**: Automatically presents Warm Silk Day Mode (`#F5F1E8`) from 6:00 AM to 5:59 PM, and seamlessly transitions to Midnight Haute Couture Night Mode (`#121115`) from 6:00 PM to 5:59 AM.
* **Manual Persistence**: User overrides via the interactive Sun/Moon button persist across all navigation turns within `sessionStorage`.

### 3. Scroll-Stitching Golden Thread (`ScrollThreadStitch.tsx`)
* A kinetic vertical margin stitch on desktop screens that dynamically threads through the layout as the user scrolls, echoing the needle and thread craft of the atelier. Respects `prefers-reduced-motion` settings.

### 4. Ambient Couture Silk Dust (`CoutureParticles.tsx`)
* GPU-composited canvas particles drifting at 60fps at `z-30 pointer-events-none`. Dynamic dual-palette rendering adapts instantly to Day and Night color temperatures.

### 5. Curated Runway Case-Study Archive (`/portfolio`)
* Real runway photography for Praweena's 3 debut fashion show collections:
  * **Fuchsia Symphony: Couture Twinning** (1st Fashion Show)
  * **Blush Petals &amp; Hand-Tufted Pompoms** (2nd Fashion Show)
  * **Celestial &amp; Avant-Garde Ensemble** (3rd Fashion Show • Theme-Based Collection)
* Features orientation-aware aspect framing (`aspect-[3/4]` portrait head-to-hem framing vs. `aspect-[16/10]` uncropped 4-model group composition), interactive dye swatches, material ledgers, and an accessible fullscreen lightbox with keyboard navigation.

### 6. Atelier Chronicles &amp; Monograph Series (`/journal`)
* Full-width (`max-w-7xl`) editorial publication layout featuring the Forthcoming Monograph Series (Volume I) researching Kovai Kora handloom preservation, Tiruppur zero-waste circularity, Dravidian temple zari architecture, and runway proportion scaling.

### 7. Bespoke Client Consultation Engine (`/contact`)
* Split-screen atelier intake form featuring localized Indian couture options (e.g. Coimbatore, Chennai, Bengaluru; Indian bridal calendar timelines; INR pricing tiers) with honeypot spam filtering and direct email dispatch.

## ✦ Local Development & Production Verification

### Prerequisites
* **Node.js**: `20.x` or `22.x` (LTS recommended)
* **npm**: `10.x` or `11.x`

### Quick Start

```bash
# 1. Clone repository
git clone https://github.com/Praweena-NS/praweena-portfolio.git
cd praweena-portfolio

# 2. Install dependencies
npm install

# 3. Start local development server (Turbopack)
npm run dev

# 4. Run ESLint validation
npm run lint

# 5. Build for production (Static Site Generation)
npm run build
```

Once started, open `http://localhost:3000` to experience the atelier in your browser.

## ✦ Accessibility & WCAG AA Compliance

* **Skip-to-Main Link**: Visually hidden link at top of `<body>` that becomes visible on `:focus`, jumping directly to `<main id="main-content">`.
* **Focus-Visible Indicators**: High-contrast `2px` focus rings (`#59469C` on light canvas, `#A998E6` on dark canvas) with `3px` offset across all buttons, inputs, links, and tabs.
* **Motion Preferences**: Respects `prefers-reduced-motion: reduce` by disabling ambient particle drift and marquee animations.
* **Semantic Structure**: Full landmark hierarchy (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`) with descriptive ARIA attributes.
